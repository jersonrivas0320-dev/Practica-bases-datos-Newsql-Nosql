## 1. Introducción

Este proyecto presenta ejercicios prácticos relacionados con el manejo de bases de datos relacionales y no relacionales, considerando su aplicación en entornos de procesamiento y gestión de datos a gran escala.

Se desarrollaron consultas SQL en SQLite y operaciones NoSQL en MongoDB, utilizando datos ficticios de productos para realizar consultas, filtros, ordenamientos, cálculos y agrupaciones.

## 2. Objetivo

Explorar y documentar operaciones básicas de bases de datos mediante ejercicios prácticos, identificando las características de los modelos relacionales y NoSQL y su utilidad en el contexto de Big Data.

## 3. Herramientas utilizadas

- **SQLite:** creación de tablas y ejecución de consultas SQL.
- **MongoDB:** almacenamiento de documentos y consultas NoSQL.
- **MongoDB Compass:** interfaz gráfica para gestionar documentos y ejecutar agregaciones.
- **GitHub:** almacenamiento y organización de los archivos y evidencias del proyecto.

**Nota:** SQLite es un sistema de bases de datos relacional y MongoDB es una base de datos NoSQL orientada a documentos. Estas prácticas no constituyen una implementación directa de una plataforma NewSQL.

## 4. Actividades desarrolladas

### Práctica SQL

- Creación de una tabla de productos.
- Consulta de registros.
- Filtrado de productos por precio.
- Ordenamiento de resultados.
- Cálculo del valor de ventas por producto.
- Agrupación de productos por categoría.

### Práctica NoSQL

- Creación de una base de datos y una colección en MongoDB.
- Inserción y consulta de documentos.
- Filtrado por producto y precio.
- Ordenamiento por precio.
- Cálculo del valor total por producto mediante agregaciones.
- Agrupación de unidades por categoría.

## 5. Estructura del proyecto

Los datos utilizados corresponden a ejemplos ficticios con fines académicos. Las capturas de pantalla documentan la ejecución de las prácticas en las herramientas correspondientes.

## 7. Conclusión

El desarrollo de estos ejercicios permitió practicar operaciones básicas de consulta y análisis de datos en modelos relacionales y NoSQL. También permitió reconocer diferencias en la estructura y manipulación de la información, así como la importancia de documentar los procedimientos y resultados.
